# Cloudflare R2 для DL-06

Создайте приватный bucket класса Standard, например `dl06-downloads`.
Отключите публичные r2.dev/custom domains. Бот выдаёт временные подписанные ссылки;
публичный сервер или туннель на ПК не требуется.

## Доставка

Файлы до 49 МБ отправляются в Telegram без обращения к R2. Крупные файлы используют
облачную ссылку автоматически. Для альбомов доступен выбор треков или ZIP по ссылке.
Формат исходный/MP3 выбирается кнопками в сообщении до скачивания.
Музыка и обычные видео не сжимаются ради Telegram. Сжимаются только крупные
TikTok/Shorts/Reels; при неудаче выдаётся ссылка на исходник.

## Ключи

`r2_config.json`: S3 endpoint, bucket, Access Key ID и Secret Access Key.
Создайте S3-ключ с Object Read & Write только для этого bucket.
Пример структуры — `r2_config.example.json`; реальный файл исключён из Git.

`cloudflare_analytics.json`: отдельный API-токен с единственным правом
Account Analytics Read вашего аккаунта. Используется для месячных операций через
GraphQL; S3 ключ не изменён. Пример — `cloudflare_analytics.example.json`.
Секреты не публиковать и не выводить в чат.

## Лимиты

- Запрос: до 2 000 000 000 байт и 200 файлов, включая ZIP.
- Пользователь: до 2 000 000 000 байт одновременно занятых им в R2.
- ADMIN_ID освобождён только от персонального ограничения.
- Общий лимит всех объектов/резерваций — 8 000 000 000 байт и 200 объектов.
- В отчёте занятость показана из 10 ГБ, рабочий лимит 8 ГБ указан отдельно.
- Лимиты проверяются атомарно в SQLite до загрузки объекта; ошибка удаления
  не освобождает квоту до успешного удаления.
- Пределы бота не являются лимитом оплаты Cloudflare.

## Сроки и базы

Ссылка: 21600 секунд (6 часов), отсчитывается после загрузки.
Бот проверяет просроченные объекты каждые 5 минут и перед загрузкой.
Настройте резервное lifecycle-правило для `dl06/`: удалить через сутки,
прервать незавершённые multipart через сутки. Действует и при выключенном ПК,
но удаление в облаке может выполняться с задержкой. Очистки «в конце дня» нет.

`_state/r2.sqlite3` хранит объекты, сроки и владельцев. Миграция с прежних шести колонок
добавляет `user_id`, сохраняя старые данные. Старые объекты без владельца остаются
в общем лимите до удаления. Личный учёт начинается для новых загрузок.
`_state/traffic.sqlite3` хранит накопленные байты трафика; не удаляйте для сохранения истории.

## Администратору

«Инфо» → «Хранилище R2» / «Статистика», либо `/storage` / `/stats`.
Только ADMIN_ID, только личный чат. Бесплатные квоты Standard A/B показаны как
1 млн / 10 млн на аккаунт; фактический счётчик отчёта — операции этого bucket за
календарный месяц МСК с кэшированием 5 минут. Это не остаток расчётного периода Cloudflare.

```powershell
.\.venv\Scripts\python.exe -X utf8 r2_admin.py check
.\.venv\Scripts\python.exe -X utf8 r2_admin.py smoke
.\.venv\Scripts\python.exe -X utf8 r2_admin.py cleanup
```

`smoke` создаёт маленький файл, загружает, скачивает по временной ссылке, удаляет
локальную и облачную тестовые копии. Ключи и подписанные ссылки не печатаются.
Служебные smoke-загрузки не входят в пользовательский счётчик трафика.

OGG/Opus/Vorbis перед любой доставкой, включая ZIP и облачные ссылки,
подготавливаются в M4A/AAC (целевые 320 кбит/с для моно/стерео).
AAC переносится без перекодирования, FLAC внутри OGG сохраняется в FLAC.
Маршрут Telegram/облако определяется по размеру готового файла после преобразования.
